## 🚀 ما أفعل  
- أعمل حالياً على مشروع **Wild Robot** — منصة مبتكرة (Flexible Web + API) تساعد في … (اختصر: «تنظيم وإدارة الأداء الرياضي والجمباز للأكاديميات»)  
- كذلك أطور **برنامج تتبّع الموظفين** – نظام يعمل على تتبّع الحضور، الساعات، والتقارير داخل بيئة عمل.  
- شغوف باستخدام تقنيات مثل Node.js، NestJS، PostgreSQL، Firebase، Supabase لتجسيد الأفكار وتحويلها إلى واقع.
