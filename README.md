# 👋 Hallo und willkommen auf meinem Profil!

Ich bin **Abdulla**, ein leidenschaftlicher Junior-Back-End-Entwickler aus den Vereinigten Arabischen Emiraten.  
Ich arbeite gern an modernen, skalierbaren Systemen, die echte Probleme lösen und Mehrwert für Teams und Organisationen schaffen.

---

## 🚀 Projekte an denen ich arbeite

### 🟢 **Wild Robot**
Eine moderne Plattform zur Leistungsbewertung von Sportlern und Turnern.  
Sie unterstützt Trainer und Sportakademien dabei, Fähigkeiten, Fortschritt und Trainingsergebnisse systematisch zu erfassen.  
- Skill-Tracking  
- Leistungsanalyse  
- Saubere UI + strukturierte API  
- Ideal für Turn- und Sportakademien

---

### 🟣 **Employee Tracking System**
Ein Workforce-Management-Tool mit:
- Geofencing  
- Automatischem Ein-/Ausloggen  
- Anwesenheitsverwaltung  
- Echtzeit-Dashboard und Berichten  

Entwickelt, um kleinen und mittleren Betrieben die Verwaltung ihrer Mitarbeiter zu erleichtern.
